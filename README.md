# Baseline Magic: The Art of Intent-Driven CSS

Commit your Code 2026 talk!

This repo holds the slides and demo site I used to give my first ever conference talk! 

The thesis is simple:
Craft with intention.
Unlock attention.

Covering some baseline widely and newly available properties, we discovered how using these new fundamental building blocks and working with our browsers, we can make sites that are more intentional and magical, bringing better experiences for our users.
